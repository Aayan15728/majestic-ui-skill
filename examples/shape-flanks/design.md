# shape-flanks: design

**Brief.** Get growth teams to book a demo by framing growth as engineering. The logo wall carries the proof.

| | |
|---|---|
| Brand (invented) | Plotline, a growth platform engineers and marketers share |
| Page title | Plotline — treat growth as an engineering problem |
| Visitor mode | Persuade |
| Use it for | B2B platforms that want to feel crafted and a little playful, agencies, design-led tools |
| Not for | calm luxury brands |
