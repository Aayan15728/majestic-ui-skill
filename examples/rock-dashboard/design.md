# rock-dashboard: design

**Brief.** Get product teams to try guided onboarding. The dashboard shows activations and influenced revenue; the rocks give the page its physical moment.

| | |
|---|---|
| Brand (invented) | Liftwell, user onboarding and activation software |
| Page title | Liftwell — more activation from every signup, faster |
| Visitor mode | Persuade |
| Use it for | B2B SaaS with a real product UI to show, growth and analytics tools |
| Not for | products with no interface to show |

## First viewport (1440 × 900)
Nav with Sign in, a black and a white pill; rails and labels; a two-line Geist Serif headline; a lead; blue and white pills; the dashboard starting at the fold.

See `web.jpg` for the desktop render and `mobile.jpg` for 390 × 844.

## Page structure
1. Hero with rails.
2. Dashboard: sidebar, breadcrumb and search, two KPI cards, a dot-matrix chart, an agent panel.
3. Boulders and fog over the dashboard's lower edge.

## Components
- **CTA:** Glossy blue pill + white pill.
- **Proof:** The dashboard's own numbers (placeholders).
- **Preview:** A full app window with three panes.

## Mobile (390px)
- Side rails, labels and matrices hide.
- The dashboard drops its sidebar and agent panel.
- Boulders scale down.

## Copying it
Copy `index.html`, keep the structure and spacing, and replace the brand, copy, data and (if the user has their own) tokens and fonts. All names, numbers and quotes in the file are placeholders.
