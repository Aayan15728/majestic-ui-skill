# pixel-forge: design

**Brief.** Get people to type their first prompt. The grove is what a result looks like; the prompt box sits right on it.

| | |
|---|---|
| Brand (invented) | Bitgrove, an AI pixel-art generator |
| Page title | Bitgrove — turn your ideas into pixel art |
| Visitor mode | Experience |
| Use it for | creative AI tools, games, pixel and retro products |
| Not for | serious enterprise software |

## First viewport (1440 × 900)
Nav with a pixel logo, three links, a dashed Log in and a double-ring Sign up; a two-line pixel headline; a lead; the grove with the prompt; legal line.

Copy `index.html`, keep the structure and spacing, and replace the brand, copy, data and (if the user has their own) tokens and fonts. All names, numbers and quotes in the file are placeholders.
