# stream-lines: design

**Brief.** Get teams with inference bills to talk to sales. The streams show many models feeding one decision.

| | |
|---|---|
| Brand (invented) | Relaywise, an inference router that picks the model per request |
| Page title | Relaywise — AI inference tailored to your use case |
| Visitor mode | Persuade |
| Use it for | AI infrastructure, routing, APIs, data pipelines |
| Not for | consumer apps |

## First viewport (1440 × 900)
Hairline-bottomed nav with a blue rect button; a centered card holding a live token count, a two-line headline, a lead, a full-width blue button and an underlined demo link.

See `web.jpg` for the desktop render and `mobile.jpg` for 390 × 844.

1. Single-screen hero card over the streams.

## Components
- **CTA:** Full-width solid blue rect + underlined text link.

- **Preview:** The card itself is the interface; the streams are the system.
