# Next.js starter

`examples/sections-kit` ported to Next.js 16 (App Router) with the Geist family from `next/font`, light and dark themes, and four small client islands: the theme toggle, the tabbed revenue board, the billing switch and the dotted-hills canvas. Everything else is a server component.

```bash
npm install
npm run dev          # http://localhost:3000
npm run check:ui     # build, start, then the majestic-ui lint and render check (set MAJESTIC_UI_DIR if needed)
```

Read `../../references/nextjs.md` for how each part of an example maps to Next.js. Replace the brand, copy and numbers; they are placeholders.
