# fluted-glow: design

**Brief.** Get platform and security teams to try a control point for agent actions. The stat line under the buttons gives the scale.

| | |
|---|---|
| Brand (invented) | Bastion, a control layer that governs every action an AI agent takes |
| Page title | Bastion — govern every action for every AI agent |
| Visitor mode | Persuade |
| Use it for | security, governance and infrastructure brands that want drama |
| Not for | the default case; it breaks the purple and gradient defaults on purpose |

## First viewport (1440 × 900)
Black bar with a lime chip and lime rule, italic serif wordmark, mono uppercase links, white and black rect buttons; a centered two-line headline, a lead, two rect buttons and a stat line.
