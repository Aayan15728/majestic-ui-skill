# dusk-range: design

**Brief.** Get Mac users to download the trial. The editor window with an annotation shows the product doing its job.

| | |
|---|---|
| Brand (invented) | Snapframe, a Mac app for screenshots and recordings |
| Page title | Snapframe — capture, edit, organize and share in one place |
| Visitor mode | Persuade |
| Use it for | consumer and prosumer desktop apps, creative tools, anything with a calm, scenic voice |
| Not for | dense B2B tools |

## First viewport (1440 × 900)
A dark pill nav centered, a two-line white headline, a short lead, one sky-blue CTA, a fine-print line with icons, the editor window crossing the fold.

See `web.jpg` for the desktop render and `mobile.jpg` for 390 × 844.

## Page structure
1. Scenic hero.
2. Editor window: toolbar, a captured photo, an arrow, a crop box and a note.

## Components
- **CTA:** One sky-blue glossy pill with a device icon.
- **Proof:** Trial and no-card line.
- **Preview:** An editor window showing an annotated capture.

## Mobile (390px)
- Nav keeps Log in and Download.
- CTA full width; the toolbar drops tools; the note stays on one line.

## Copying it
Copy `index.html`, keep the structure and spacing, and replace the brand, copy, data and (if the user has their own) tokens and fonts. All names, numbers and quotes in the file are placeholders.
