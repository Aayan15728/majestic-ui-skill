# pixel-photo: design

**Brief.** Get developers to start building travel booking into their agents. The API line under the buttons shows a real response time.

| | |
|---|---|
| Brand (invented) | Wayline, a travel booking API for AI agents |
| Page title | Wayline — the travel infrastructure built for agents |
| Visitor mode | Persuade |
| Use it for | APIs and infrastructure with a lifestyle angle: travel, food, events, mobility |
| Not for | dark technical brands |

Black announcement bar, logo tile left, a white nav box right with coral Sign up; a two-line headline, a mono lead, coral and white rect buttons, an API response chip.
