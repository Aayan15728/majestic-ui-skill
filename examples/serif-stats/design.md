# serif-stats: design

**Brief.** Get makers to list their product today by proving the directory sends traffic. The stats and the live board carry the page.

| | |
|---|---|
| Brand (invented) | Launchyard, a product directory where makers list and get discovered |
| Page title | Launchyard — list your product, get found |
| Visitor mode | Persuade |
| Use it for | directories, communities, ads and media pages |
| Not for | pages without real numbers to show |

## First viewport (1440 × 900)
Classic nav, a promise-plus-qualifier headline over two lines, a lead, a primary pill with a price link, then three stat cards.

See `web.jpg` for the desktop render and `mobile.jpg` for 390 × 844.

## Page structure
1. Hero.
2. Stat cards on #f4f4f6 with sources.
3. Live leaderboard of listed products.

## Components
- **CTA:** Accent pill + price link.
- **Proof:** Three stat cards with source captions.
- **Preview:** A live leaderboard.

## Mobile (390px)
- Stat cards stack.
- Board rows truncate names with an ellipsis.

## Copying it
Copy `index.html`, keep the structure and spacing, and replace the brand, copy, data and (if the user has their own) tokens and fonts. All names, numbers and quotes in the file are placeholders.
