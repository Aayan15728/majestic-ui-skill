    Questions, answered.

    How do I install Sumlight?
    Add the script to your site's head tag. Page views are recorded on their own, and you can send your own events from the browser. Setup walks you through each step.
    Read the install guide
    Does Sumlight use cookies?
    No. Visits are joined with a daily salted hash that can't be traced back to a person, so you don't need a consent banner for Sumlight.
    How does revenue tracking work?
    Connect your billing provider once. Each payment is matched to the visit that started the session, and refunds are taken off automatically.
    Can I track more than one website?
    Pro covers five websites and Team covers as many as you like. Each site gets its own dashboard and its own share link.
    Can I export my data?
    Any view exports as CSV in one click, and the REST API returns the same numbers. If you leave, you take everything with you.
