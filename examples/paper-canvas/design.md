# paper-canvas: design

**Brief.** Get designers and engineers to download the app. The window shows a real file open, with people in it.

| | |
|---|---|
| Brand (invented) | Folio, a design canvas that teams and coding agents share |
| Page title | Folio — the connected canvas for teams shipping with agents |
| Visitor mode | Persuade |
| Use it for | design and creative tools, editors, documentation and writing products |
| Not for | loud consumer brands |

## First viewport (1440 × 900)
Lowercase nav; a three-line headline left; a lead; a dark rect button and a text link; the folded corner right; the app window from the fold.

See `web.jpg` for the desktop render and `mobile.jpg` for 390 × 844.

## Page structure
1. Hero with the app window.
2. Hairline grid: two feature cells, then a wide cell with a big heading and the staircase.

## Components
- **CTA:** Dark rect button + quiet text link.
- **Proof:** Avatars in the file and real-looking track data.
- **Preview:** A design tool with tabs, pages, tools, an artboard and properties.

## Mobile (390px)
- Links and the corner hide.
- The window keeps only the artboard.
- Grid cells stack.

## Copying it
Copy `index.html`, keep the structure and spacing, and replace the brand, copy, data and (if the user has their own) tokens and fonts. All names, numbers and quotes in the file are placeholders.
