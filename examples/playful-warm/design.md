# playful-warm: design

**Brief.** Show creators that dull numbers can become posts people stop for. The headline literally contains the platforms.

| | |
|---|---|
| Brand (invented) | Bragcard, a tool that turns creator stats into shareable images |
| Page title | Bragcard — your numbers, made worth sharing |
| Visitor mode | Persuade |
| Use it for | creator and indie tools that want to feel playful |
| Not for | serious finance, health or enterprise products |

## First viewport (1440 × 900)
Nav, a three-line chunky headline with inline platform tiles, a lead, a glossy orange button, an avatar proof row, then the card preview.
