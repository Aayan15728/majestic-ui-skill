# cinematic-black: design

**Brief.** Show Mac power users that everything they copied is one keystroke away. The command palette over a desktop scene is the whole argument.

| | |
|---|---|
| Brand (invented) | Shelf, a clipboard history app for Mac |
| Page title | Shelf — clipboard history for Mac |
| Visitor mode | Persuade |
| Use it for | premium desktop apps and utilities |
| Not for | bright consumer brands or B2B pages that need a lot of copy |

## First viewport (1440 × 900)
Minimal nav, a two-line Newsreader headline in near-white and grey, a short lead, a white pill and a dark pill, then the desktop scene with the palette open.
