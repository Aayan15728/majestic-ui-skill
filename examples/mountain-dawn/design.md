# mountain-dawn: design

**Brief.** Get climbers to plan tomorrow's route with sun timing and snow lines. The cards show the three things paper maps can't.

| | |
|---|---|
| Brand (invented) | Switchback, an alpine route-planning map app |
| Page title | Switchback — plan alpine routes before the light does |
| Visitor mode | Persuade |
| Use it for | outdoor, travel, maps and calm premium brands |
| Not for | bright playful products |

## First viewport (1440 × 900)
Nav, a mono conditions line, a centered two-line serif headline in the sky, a lead, a light and a black rect button above the peaks.

See `web.jpg` for the desktop render and `mobile.jpg` for 390 × 844.

## Page structure
1. Sky hero.
2. Logo strip.
3. Three hairline-split feature cards with small data drawings.

## Components
- **CTA:** Light rect + black rect, radius 2.
- **Proof:** Logo strip.
- **Preview:** Data drawings inside the feature cards.

## Mobile (390px)

## Copying it
Copy `index.html`, keep the structure and spacing, and replace the brand, copy, data and (if the user has their own) tokens and fonts. All names, numbers and quotes in the file are placeholders.
