# pixel-panel: design

**Brief.** Show that agents can work right where files already live. The file browser breaking out of the panel is the moment.

| | |
|---|---|
| Brand (invented) | Burrow, a Mac app that runs agents next to your files |
| Page title | Burrow — your agents, where your files live |
| Visitor mode | Persuade |
| Use it for | Mac and productivity apps |
| Not for | brands that can't carry a strong color |
