# ascii-workspace: design

**Brief.** Show developers that all their coding agents can share one local workspace. The app window proves it with a real diff.

| | |
|---|---|
| Brand (invented) | Tandem, a local workspace for running coding agents side by side |
| Page title | Tandem — every coding agent, one local workspace |
| Visitor mode | Persuade |
| Use it for | open-source and developer desktop tools |
| Not for | non-technical consumer audiences |
